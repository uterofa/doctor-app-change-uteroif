## Решение по видеоконсультациям

**Вопрос заказчику:** Готовы ли мы пожертвовать какими-то менее важными задачами из текущего бэклога и перенести их на будущее, чтобы внедрить видеоконсультации без увеличения общего бюджета и сдвига сроков?

**Категория MoSCoW:** Must

**Влияние на сроки:** Сроки увеличатся 

**Влияние на бюджет:** Бюджет возрастет

**Решение:** взять сейчас

**Почему:** Заказчик прямо указал на критичность требования, озвучив формулировку: это критически важно.
